# 创新性论证

## 1. 从“关键词列表”升级为可执行约束图

传统查询分解只产出多个字符串。ScholarNexus 同时给每条约束绑定执行角色：元数据硬过滤、
召回锚点、语义核验和排除项，并用 AND/OR/NOT 语义显式组织别名与组合条件。
创新点不在“让 LLM 多生成几个词”，而在同一约束图贯穿召回、排序、矩阵展示和审计。

## 2. 相关集合规模参与输出决策

固定 Top-K 无法同时适配单篇定位和领域综述。系统用多通道重叠估计相关集合规模 N̂，
再将校准概率交给期望 F1 前缀选择。F1 半阈值理论已有文献，本项目贡献是把它与
捕获–再捕获、标注倾向性和学术引文发现组合为查询自适应的集合决策。

## 3. 消融驱动的成本控制

融合前原型的 L3 和多轮演化在离线消融中没有正收益。新版本没有为了“看起来像Agent”
而保留无效调用，而是默认关闭，并保留 VoI 触发入口。离线夹具上平均 LLM 调用从8.5次
降至1.86次，Macro-F1反而从0.5131升至0.5399。

## 4. 双路径概率校准

没有标注时使用混合分布与独立质量锚点；具备严格开发集时可加载轻量监督特征校准器。
测试集永不参与拟合，模型文件记录特征版本、训练集名称和混合权重。

## 5. 结构化结果不是装饰

输出视图由查询类型选择。定位查询给消歧表，综述给分面与时间线，基准查询给数据集/指标
矩阵，所有类型共享约束满足矩阵、来源通道和调用账本。结构化字段直接来自检索状态，
不是对生成文本的二次排版。
