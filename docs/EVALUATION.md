# 评测说明

## 离线回归夹具

- 语料：618篇合成论文，包含标题、摘要、年份、venue、引用与被引边。
- 查询：21条，含18条集合检索和3条单篇定位。
- 用途：验证管线、消融和成本；不得将结果称为公开榜单成绩。

当前结果见 `docs/eval/main.json`：

| 指标 | 数值 |
|---|---:|
| Macro Precision | 0.4135 |
| Macro Recall | 0.8436 |
| Macro F1 | 0.5399 |
| Micro F1 | 0.5139 |
| Recall@20 | 0.6460 |
| 平均 LLM 调用 | 1.86 |
| 平均 tokens | 1082.8 |
| 结构化得分 | 0.7833 |
| 赛题权重模拟综合分 | 0.6563 |

关键消融见 `docs/eval/ablation.json`：F1-Gate比Top-20高0.1085；关闭引文扩散
使F1降至0.2712；关闭倾向性修正使F1降至0.5122。L3和多轮演化默认未启用，
因此相应“关闭”消融与主方案相同，这是有意的诚实基线。

## 公开 SPAR

项目包含1000条 `AutoScholarQuery_test.jsonl` 和统一评测脚本。匹配优先使用规范化
arXiv ID，其次使用规范化标题精确匹配。当前交付包不伪造ScholarNexus的真实API分数；
需要配置可用服务后，在固定模型、统一预算和至少100条样本上运行。

## 已验证工程性质

- 44/44 测试通过；
- Python全量编译通过；
- 评测两次运行指标一致；
- 外部源故障、LLM垃圾输出、预算耗尽和空结果均有回退；
- 论文版本去重合并不会污染共享离线语料。
